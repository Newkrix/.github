# Newkrix

A desktop [Matrix](https://matrix.org) client built with Rust and Tauri. Fast, native, and themeable.

## Features

- **Rooms and spaces:** space lobbies, subspaces, room and space settings, explore, and a quick switcher.
- **Calls:** voice and video with a flat or 3D call view, raise hand, reactions and a pop-out window.
- **Themes:** gradient presets and a custom theme builder, with light, dark and OLED looks.
- **Profiles:** banners and customizable Home icons.
- **Messaging:** threads, rich link embeds and sticker packs.
- **Languages:** English, Brazilian Portuguese and Latin American Spanish.
